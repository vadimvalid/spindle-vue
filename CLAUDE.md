# Spindle (учебный проект)

Nuxt 4 + Vue 3 + AI SDK (Gemini). План и прогресс — в [docs/ROADMAP.md](docs/ROADMAP.md).
В начале сессии прочитай его, чтобы понять, на каком шаге мы остановились.

## Формат работы

- Я учусь и пишу код сам. Не редактируй файлы проекта, пока я явно не попрошу.
- Давай подробные пошаговые инструкции на русском: фрагменты кода, объяснение *зачем*,
  и раздел «Как проверить» для каждого шага. Если я застрял — покажи код шага целиком с комментариями.
- На «проверь» — прочитай файлы, сам прогони проверки (curl к `localhost:3000`, headless Chrome)
  и укажи конкретные строки с ошибками.
- После завершения шага обнови `docs/ROADMAP.md` (это можно делать без отдельного запроса).

## Соглашения

- Общие типы/схемы — в `shared/` (алиас `#shared/...`), серверные утилиты — в `server/utils/` (автоимпорт).
- Ошибки компиляции сгенерированного кода — это ответ `200 { ok: false, errors }`, а не `createError`.
